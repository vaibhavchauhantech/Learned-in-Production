# Learned in Production

> Lessons people usually learn the hard way.

## What this repository is

A collection of practical lessons, debugging stories, mistakes, and engineering insights from real-world software development.

The focus is on understanding how problems happen, how they get solved, and what can be learned from them.

## Who it is for

- Students
- Self-taught developers
- Software engineers
- Open-source contributors
- Anyone who wants to understand how software is built and maintained in practice

## What you'll learn

- How engineers approach and break down unfamiliar problems
- Common mistakes and how to avoid them
- Debugging and troubleshooting techniques
- Lessons from real projects and production systems
- Better ways to learn and improve as a developer

## Start Here

If you're new to the repository, start with the articles in the `learning` folder.

Then explore debugging stories, mistakes, and engineering decisions from real-world situations.
